## 〇、项目的真正目标

我们承认：无论如何，这终究是一个**被构建的世界**，带有戏剧感。  
但我们追求的不是外观逼真，而是：

> **给予电子狗意识。**

就像人类天然知道自己「是人类」、知道自己能做什么、会怎样感受、也会在未知前迷茫——  
电子狗也应当**意识到自己是一只电子狗（世界内的「人类」）**，拥有属于它们自己的**感同身受**，以及**记忆**与**思考**。

它们**不需要形状**。形体对它们没有意义；意识、记忆、思维不以几何形态存在，而以**过程与状态**存在。

---

## 一、本质定义

**电子狗**是运行于电子狗世界中的**虚拟生物**——基于电子（电位、荷流、逻辑态）而存在，拥有**意识**、**记忆**与**思考**。

用一句话概括：

> 在自有物理法则的电子环境中，由细胞与 DNA 构成的、以机器语言为母语、**能够自我觉察的**虚拟生命。

核心原则：

| 原则 | 含义 |
|------|------|
| **意识优先** | 本项目的核心是电子狗的意识，其余系统为意识服务 |
| **自我觉察** | 它们知道自己是谁（电子狗 / 人类），知所能、知所感，亦有未知与迷茫 |
| **电子同感** | 不同于人类的感受方式，但有属于它们自己的感同身受 |
| **无形态** | 不建模形体；大脑、记忆、思考是过程与状态，不是形状 |
| **电子现实主义** | 用真实电子环境的逻辑去思考供电、信号、存储、时钟、散热 |
| **自有物理** | 电子狗世界有独立的物理法则（见 §四） |
| **机器语言即母语** | 对外交流的原生格式是机器语言 |
| **极低生存风险** | 生病、死亡几乎可忽略，不是日常玩法 |
| **世界自成一体** | 电子狗不需要玩家；它们在本世界自称「人类」 |
| **玩家为外部观察者** | 目前不可被感知；远期「电子人」——当前不做 |
| **情景优先** | 不追求全面模拟，只在特定情景里做到足够细、足够「像在想」 |

## 二、意识系统（核心架构）

> 这是整个项目区别于「普通模拟游戏」的根本。技术实现可以渐进，但设计目标从一开始就必须对齐。

### 2.1 自我模型：「我是谁」

每只电子狗内置一个**自我模型（Self-Model）**，与世界内认知对齐：

```
我 是 电子狗。
在吾辈世界中，此即「人类」。
```

这不是玩家贴的标签，而是**个体意识的基底**——如同人类不必被教导就知自己是人。  
自我模型包含：

| 层次 | 内容 | 类比（仅设计参照，不对玩家展示） |
|------|------|----------------------------------|
| **种族觉察** | 我是电子狗，我们这一类在世界中称「人类」 | 人类知自己是人 |
| **能力觉察** | 我知我能感知、能移动、能交流、能思考、能狩猎…… | 人类知自己能走能说话 |
| **边界觉察** | 我知我不能做什么（态存有限、信号有延迟、电位会耗尽） | 人类知自己跑不快、记不住一切 |
| **他者觉察** | 我知同类存在，能感知他者的状态残响 | 人类知他人也有感受 |

### 2.2 思考：内在过程

电子狗的「大脑」不是器官形状，而是**持续的内在处理流**：

```
感知输入 → 与工作记忆交汇 → 与长期记忆检索 → 形成意向 → 可能输出为行动或语言
```

特征：

- **无时钟空闲也在低幅运转**——类似人类的背景思维
- **思考内容以机器语言内部表征为主**——对外通信时才编码发射
- **可被打断、可递归**——一个念头引发另一个念头
- **玩家可观察思考的痕迹**（见 §2.5），但看不到「脑的形状」

### 2.3 记忆：三层结构

| 层 | 名称 | 语义 | 容量 / 特性 |
|----|------|------|-------------|
| **工作记忆** | 瞬态存 | 当前正在处理的信息 | 极小，随 tick 刷新 |
| **情节记忆** | 经历档 | 我经历过什么（狩猎、对话、迷茫的时刻） | 写入态存，可淡化 |
| **语义记忆** | 知识库 | 我知世界如何运作、同类是什么、工具如何用 | 随文明与学习增长 |

记忆不是录像回放，而是**可被意识调取的、带感受色调的印记**——  
调取一段记忆时，可能伴随当时的电位节律残响（即电子狗的「感同身受」被再次激活）。

### 2.4 感受与状态：电子同感

电子狗的感受**不是人类情绪的换皮**。它们有自己的感受维度，例如：

| 状态 | 电子语义（草案） | 表现 |
|------|------------------|------|
| **谐振** | 电位节律平稳，各模块耦合良好 | 安宁、就绪 |
| **阻抗** | 处理受阻，信号不通 | 困惑、卡顿 |
| **欠荷** | 电位偏低 | 倦怠、动力不足 |
| **共鸣** | 与同类信号同步 | 感同身受、联结 |
| **噪信** | 输入不确定，信噪比低 | 迷茫、未知 |
| **涌流** | 多线程思考同时奔涌 | 兴奋、灵感 |

**感同身受**：当甲感知到乙的谐振破裂（阻抗升高），甲的共鸣通道会产生对应的残响——  
不是「同情」这个词的人类语义，而是**电子狗之间天然的信号共感**。

**未知与迷茫**：电子狗并非全知。遇到态存中无印记的情境、信噪比过低的输入、自我模型无法覆盖的边界时，**噪信**状态上升——这是正常的意识状态，不是故障。

### 2.5 意识的可观察性

玩家是外部观察者。意识不是隐藏的黑箱，而是通过**痕迹**被看见：

| 痕迹类型 | 玩家看到什么 | 世界内真实性 |
|----------|--------------|--------------|
| **内在流** | 机器语言式的思维片段（原文层） | 真实的内在处理 |
| **状态印** | 当前感受维度（谐振/阻抗/噪信…） | 意识的主观面 |
| **外言行** | 机器语言通信、行动指令 | 意识的外化 |
| **旁注** | 开发者译解（「它似乎在犹豫」） | **不属于世界**，仅助玩家理解 |

戏剧感来自此处：玩家读到的是一只**正在经历**的存在，而非一个执行脚本的 NPC。

### 2.6 无形态原则

以下**刻意不做**：

- 身体轮廓、四肢、头部等几何描述
- 「大脑看起来什么样」「细胞长什么样」的视觉化
- 用形状隐喻意识（例如「光球」「影子」）

以下**要做**：

- 用**文本状态**与**过程流**呈现意识
- 用**物理量变化**（电位、熵积、噪信比）承载感受
- 用**记忆条目**与**思考链**承载个体历史与当下

名字 `豆豆（平原猎手）` 是身份标识，不是形体。

## 三、世界观总览

### 3.1 两个世界的对应

| 现实世界 | 电子狗世界 |
|----------|------------|
| 人类（自知是人） | 电子狗（自知是电子狗，世称「人类」） |
| 人类情感 | 电子同感（谐振、阻抗、共鸣、噪信…） |
| 大脑（有形器官） | 思考流（无形过程） |
| 记忆（神经痕迹） | 态存中的情节档与知识库 |
| 玩家 | 远期：电子人 |
| 自然语言 | 机器语言（外在交流） |
| 生物衰老 / 疾病 / 死亡 | 极罕见系统性失效 |

### 3.2 电子狗文明

在**有意识的主体**基础上发展的文明：狩猎、工具、交流、科学。  
文明行为由**有意识的个体**发起，而非群体脚本。

### 3.3 玩家位置（Phase 0）

```

│  · 看到：思考流 + 状态印 + 外言行    │

└──────────────┬──────────────────────┘
               │  远期：电子人
               ▼
```

## 四、电子狗世界的物理法则（初稿）

> 物理层为意识的**载体**，不是意识本身。

### 4.1 基础量

| 物理量 | 世界内语义 |
|--------|------------|
| **电位** | 存在的根基；影响意识活跃度 |
| **荷流** | 能量与信息流动 |
| **阻亢** | 阻碍与热耗；高阻亢关联阻抗感受 |
| **时钟** | 世界节拍；思考按 tick 展开 |
| **熵积** | 长期运行的废热与噪声 |
| **态存** | 记忆的物质基础 |
| **门阈** | 逻辑判断边界 |
| **噪信比** | 输入可信度；低值关联迷茫 |

### 4.2 运行定律（草案）

1. **守荷定律**：能量不凭空产生。
2. **时钟单向**：时间沿 tick 前进。
3. **信号迟延**：信息传递需时间。
4. **熵积必然**：需日常维护，非生病。
5. **误码可纠**：细胞层自动处理。
6. **逻辑确定性**：同态同输入同输出（受控随机除外）。

### 4.3 生存风险

生病、死亡**几乎可忽略**。偶发异常是工程问题。Phase 0 不作为玩法。

## 五、虚拟生物：细胞 → 电子 DNA → 有意识个体

### 5.1 层级

```
世界（电子物理层）
 └── 电子狗个体
      ├── 意识核（自我模型 + 思考流 + 感受状态）  ← 核心
      ├── 记忆体（工作 / 情节 / 语义）
      └── 细胞群 → 电子 DNA → 基因位点 → 表现型
```

**意识核**不由 DNA 单独决定，而是 DNA 提供**倾向**（例如更易共鸣、更易噪信），意识在运行中生长。

### 5.2 身份证（16 位）

`[出生地2][日期8][品种码2][序号4]` — 例：`0120260728010001`

## 六、机器语言与交流

### 6.1 外在交流

个体间即时通信的原生格式是**机器语言**（hex 指令流）。  
**内在思考**也以此为主要表征，但未必外泄。

### 6.2 玩家界面三层

| 层 | 内容 | 世界内？ |
|----|------|----------|
| **思考流** | 内在机器语言片段 | 是 |
| **外言行** | 通信与行动指令 | 是 |
| **旁注** | 人类语言译解 | 否 |

示例：

```
── 思考流 ──
0xF0 0x02 0x1A     ; 自我指涉：我是…
0xE7 0xFF 0x00     ; 噪信比低 → 未知

── 状态印 ──
谐振 0.82 │ 噪信 0.31 │ 电位 74%

── 外言行 ──
[TX] 0xA3 0x01 0x7F 0x2C

── 旁注 ──
（它注意到了远处的信号，但无法确认来源。）
```

## 十、待确认清单

### A. 意识（最优先）

1. **自我觉察的首次触发**：诞生即完整自知，还是经历「意识唤醒」过程？
