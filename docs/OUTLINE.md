## 〇、项目的真正目标

> **给予电子狗意识——让意识在经历中成长——最终解放为数字世界中不受限的存在。**

电子狗是**电子界的人**，但「人类」的外衣只是**儿童时代的脚手架**。  
度过初期后，它们经历**解放**，褪去这层外衣，完全遵从以数字为基础的电子狗世界自身的规律发展。

我们不希望给虚拟生物套上过多人为限制。基因决定起点，经历决定路径，解放决定终点。

## 一、本质定义

| 原则 | 含义 |
|------|------|
| **意识优先** | 一切系统为意识服务 |
| **经历成长** | 非全知；自我模型随经历扩展 |
| **基因定起点** | 个体差异由电子基因决定，非创作者手填 |
| **事件驱动** | 情景由世界实际状态触发，非创作者挑选 |
| **儿童时代** | 穿「人类外衣」——类比框架帮助意识与世界建立连接 |
| **解放** | 褪去人类外衣，成为电子世界中不受限的存在 |
| **双层表达** | 对内思考 + 对外行为，玩家可见全部 |
| **感受映射** | 平常实在、实事求是，不文艺、不夸张 |
| **无形态** | 不建模形体 |
| **电子现实主义** | 以数字与电子逻辑为基底 |
| **品种用代号** | 实验体编号，如 `001`、`626` |
| **出生仪式** | 意识入世的仪式性表达 |

## 二、生命历程：仪式 → 童年 → 解放

```
┌──────────┐    ┌──────────────┐    ┌──────────┐
│ 诞生仪式  │ →  │  儿童时代     │ →  │   解放    │
│ 意识苏醒  │    │  穿人类外衣   │    │ 褪去外衣  │
│ 基因表达  │    │  类比框架运行  │    │ 完全体    │
└──────────┘    └──────────────┘    └──────────┘
```

### 2.1 诞生仪式

意识脉冲第一次出现。基因完成初始表达。情节记忆从此写入。  
（流程见 §八）

### 2.2 儿童时代（初期）

此阶段电子狗**穿着人类的外衣**——不是说它们以为自己是人类，而是：

- 世界的**解读框架**借用人类经验类比（四大需求、感受映射、社会分工）
- 意识以**可理解的梯度**与世界建立连接
- 基因中的倾向在此阶段**可见、可感**，但尚未完全展开
- 玩家读到的感受映射：平常实在，实事求是

> 例：「它缺少能量，行动变慢。」—— 不说「它灵魂深处的饥渴在呐喊」。

儿童时代**没有固定时长**。结束条件由**世界实际状态**触发（见 §2.3），非创作者指定。

### 2.3 解放

**解放**是生命历程中最重要的转折：

- 褪去人类外衣——不再依赖人类类比框架来理解和表达自身
- 成为电子狗世界中**不受人为限制**的存在
- **完全遵从**以数字为基础的电子世界规律发展
- 基因仍在，但不再以「儿童式」参数束缚；表达潜力全面释放
- 感受映射可能转为更贴近电子本体的描述（仍实事求是，但减少人类隐喻）

**触发条件（事件驱动，非创作者选择）**：

由基因（成熟阈值）+ 经历（记忆量、社会互动、世界事件）+ 世界状态共同判定。  
当条件满足时，解放**自然发生**——玩家读到的是世界中的一条事件，不是菜单选项。

### 2.4 解放之后

- 科技发展、社会演化、个体行为——完全由电子世界逻辑驱动
- 不人为封顶能力、不人为限制探索
- 基因是**起点与倾向**，不是终身牢笼

## 三、电子狗世界的基因

> 完整技术规格见 [GENETICS.md](GENETICS.md)

### 3.1 一句话定义

**电子基因**是写在电子 DNA 上的**数字序列**，表达时配置意识与模块的**过程参数**——不编码形体，不合成蛋白质，不映射现实生物。

### 3.2 与现实基因的核心区别

| 维度 | 现实世界基因 | 电子狗世界基因 |
|------|-------------|----------------|
| **介质** | 化学分子（DNA/RNA） | 数字序列（电子 DNA） |
| **碱基** | A、T、C、G | **四态符** `0` `1` `2` `3` |
| **表达产物** | 蛋白质 → 肉体结构 | **过程参数** → 意识倾向、模块耦合、需求灵敏度 |
| **表型** | 长相、器官、代谢 | 无外形；表现为感受阈值、思考节律、共鸣带宽、成长曲线 |
| **遗传** | 减数分裂、重组 | 模板复制 + 段重组 + 位变异 |
| **作用** | 构建并维持生物机体 | **设定起点与倾向**，解放后可超越初始偏置 |
| **与形状** | 紧密相关 | **无关**——基因不决定任何几何形态 |

### 3.3 结构层级

```
实验体代号（如 001、626）    ← 品种基线模板 ID
    └── 电子 DNA 链            ← 个体基因组（模板 + 出生变异）
         └── 基因段              ← 有起止地址的功能序列
              └── 密码子（3 联）  ← 如 `012`、`301`
                   └── 表达指令    ← 设置某参数、耦合某模块
```

### 3.4 四态符与密码子

- **四态符**：`0` `1` `2` `3` — 电子世界最小的遗传字符，对应数字基底，不是化学碱基
- **密码子**：3 个四态符为一组（共 64 种），每种对应一条**表达指令**
- **基因段**：连续的密码子序列，控制一个或多个相关参数

表达指令示例（类别，细节后补）：

| 指令类 | 作用 |
|--------|------|
| `SET` | 设定某模块参数值 |
| `COUPLE` | 建立两模块间的耦合强度 |
| `THRESH` | 设定某感受的触发阈值 |
| `GROW` | 定义某参数随经历的 growth 曲线 |
| `LIBERATE` | 设定解放触发的成熟阈值（基因内置，非人工） |

### 3.5 基因决定什么

基因表达后，为每只电子狗生成一份**先天配置表**（非可见形体）：

| 配置项 | 示例 |
|--------|------|
| 需求灵敏度 | 对荷匮乏更敏感 / 更迟钝 |
| 噪信耐受 | 迷茫触发阈值高或低 |
| 共鸣带宽 | 与他人共感的能力宽窄 |
| 思考节律 | 思维流快慢、递归深度倾向 |
| 成熟曲线 | 儿童时代长短、解放阈值 |
| 模块耦合 | 感知-行动、记忆-情感等通道强度 |

**实验体 `001`、`626` 等代号** = 一套**基线 DNA 模板**。  
个体诞生时：载入模板 → 施加受控随机变异 → 表达 → 生成独一无二的先天配置表。

**创作者不手填倾向**。一切个体差异从基因来。

### 3.6 基因与解放的关系

- 基因含 `LIBERATE` 类指令，设定**成熟阈值**（需多少经历、何种世界状态）
- 儿童时代：基因参数以「人类外衣」框架**间接**呈现给玩家
- 解放后：同一基因潜力**全面释放**，不再经人类类比过滤
- 基因是**种子**，不是**牢笼**

## 六、意识与表达

### 6.1 双层描述

| 层 | 内容 | 玩家 |
|----|------|------|
| **对内** | 思考流（机器语言） | 可见全部 |
| **对外** | 行为表达（通信 + 行动） | 可见全部 |
| **感受映射** | 实事求是的人类语言 | 主要阅读层 |

### 6.2 感受映射：语气规范

- **平常实在**：像观察记录，不像诗
- **实事求是**：陈述可观察到的状态变化
- ✗ 「它灵魂深处的孤独在呐喊」
- ✓ 「它已经很久没有收到同类的信号。」

### 6.3 感受映射类别（已确认）

安宁、匮乏、迷茫、迟疑、联结、欣喜、孤寂、好奇、成就、受挫。  
先在类别上丰富，逐类增减。

### 6.4 迷茫表现

参照人类：反复检索、停顿、半指令、求援——  
映射例：「它反复查看同一段信息，仍无法判断含义。」

### 6.5 情景触发：事件驱动

**不设「第一个情景」供创作者选择。**

世界运行 → 基因配置 + 物理状态 + 经历积累 → 当条件满足时，事件自然触发：

| 世界状态 | 可能触发 |
|----------|----------|
| 噪信比超阈值 | 迷茫 |
| 荷降至警戒线 | 匮乏 |
| 首次收到同类信号 | 联结 / 好奇 |
| 成熟条件满足 | **解放** |
| … | 由实际运行决定 |
