## 一、本质定义

**电子狗**是运行于电子狗世界中的**虚拟生物**——它们基于电子（电压、电流、逻辑态）而存在，不是现实犬类的仿制品，也不是科幻设定里的「数字灵魂」。

用一句话概括：

> 在遵循自身物理法则的电子环境中，由细胞与 DNA 构成的、以机器语言为母语的自洽生命形式。

核心原则：

| 原则 | 含义 |
|------|------|
| **电子现实主义** | 用真实电子环境的逻辑去思考——供电、信号、存储、时钟、散热、误码纠错；拒绝科幻化 |
| **自有物理** | 不套用现实生物学，也不套用现实牛顿力学；电子狗世界有**自己的物理法则**（见 §三） |
| **机器语言即母语** | 它们之间的交流是机器语言，不是人类自然语言 |
| **极低生存风险** | 参照现实电子设备：故障率极低，「生病」「死亡」几乎可忽略，不是日常玩法 |
| **世界自成一体** | 电子狗不需要玩家；它们在本世界自称「人类」，狩猎、造工具、发展科学 |
| **玩家为外部观察者** | 目前不可被感知；远期「电子人」——当前不做 |
| **情景优先** | 不追求全面模拟，只在特定情景里做到足够细 |

## 二、世界观总览

### 2.1 两个世界的对应

| 现实世界 | 电子狗世界 |
|----------|------------|
| 碳基人类 | 电子狗（世界内称「人类」） |
| 玩家 | 远期：电子人（未实现） |
| 生物解剖 / 生物基因 | 电子细胞 / 电子 DNA |
| 自然语言 | **机器语言** |
| 生物代谢 | 电能代谢 |
| 生物衰老 / 疾病 / 死亡 | 极罕见的系统性失效（几乎可忽略） |

### 2.2 电子狗文明

电子狗已具备与现代人类**同步的科学技术水平**（在它们自己的物理框架内表达），日常运转包括：

- **狩猎**——采集能量与原材料（见 §5.3）
- **工具**——制造与使用电子工具
- **交流**——以机器语言为底层的通信与协作
- **科学**——观测、实验、记录、传承

它们有社会、身份、个体独特性，但**不生活在疾病与死亡的阴影下**——就像现实里一台维护良好的设备，年复一年稳定运行；偶发异常属于工程问题，不是生存危机。

## 三、电子狗世界的物理法则（初稿）

> 这是它们世界的「自然律」，不是现实物理的简单复制，但**思维方式参照真实电子工程**。

### 3.1 基础量

| 物理量 | 世界内语义 | 现实参照（设计用，不对玩家说教） |
|--------|------------|----------------------------------|
| **电位** | 存在的根基；归零即失去活动能力 | 供电电压 |
| **荷流** | 能量与信息的载体流动 | 电流 |
| **阻亢** | 阻碍流动，产生热耗 | 电阻 |
| **时钟** | 世界节拍；一切过程按 tick 推进 | 晶振 / 时钟周期 |
| **熵积** | 长期运行产生的废热与噪声累积 | 散热 / 信噪比下降 |
| **态存** | 记忆的物质基础，有容量上限 | 存储器 |
| **门阈** | 逻辑判断的边界 | 逻辑门 |

### 3.2 运行定律（草案）

1. **守荷定律**：能量不凭空产生；狩猎与供能是文明的基础活动。
2. **时钟单向**：时间沿 tick 前进，不可回卷（局部缓存可覆写，不等于时间倒流）。
3. **信号迟延**：信息传递需要时间；距离与介质决定延迟。
4. **熵积必然**：持续运行必然积累熵积；需通过散热、维护、休整来管理——这是日常，不是生病。
5. **误码可纠**：传输与存储中的位翻转是常态；纠错机制内置于细胞层，个体几乎无感。
6. **逻辑确定性**：同一输入在同一状态下产生同一输出——除非引入受控随机源（基因变异、量子噪声抽象）。

### 3.3 与「生病 / 死亡」的关系

按电子现实主义：

| 现实电子现象 | 世界内表现 | 游戏权重 |
|--------------|------------|----------|
| 偶发位错误 | 细胞层自动纠错，无感 | 背景机制 |
| 模块过热 / 熵积偏高 | 降频、休整、散热 | 日常维护 |
| 供电中断 | 暂停运行；恢复供电后继续 | 环境事件，非死亡 |
| 存储坏块 | 迁移数据至冗余区 | 工程维护 |
| 核心损毁且无冗余 | **系统性失效** | **极罕见**，叙事级事件 |
| 永久断电且无备份 | **终止** | **极罕见**，几乎不在 Phase 0 出现 |

**结论**：Phase 0 不将「生病」「死亡」作为核心玩法；生存风险极低，可忽略。后期若引入，仅作为极端边界条件，频率接近零。

## 四、虚拟生物：细胞 → 电子 DNA → 个体

### 4.1 层级

```
世界（电子物理层）
 └── 电子狗个体（虚拟生物）
      └── 细胞群（功能模块：感知 / 运算 / 驱动 / 代谢 / 通信…）
           └── 电子 DNA（可执行基因组）
                └── 基因位点（参数、逻辑片段、耦合规则）
                     └── 表现型（体质、认知倾向、角色天赋…）
```

### 4.2 语义澄清

- **虚拟生物**：在电子物理层上表现出生命特征的自主系统——代谢（耗电）、感知（采样）、行动（输出）、繁殖（复制+变异）、适应（参数调整）。
- **细胞**：不是生物细胞，是**功能模块**的比喻，对应一组协同的逻辑单元。
- **电子 DNA**：决定个体初始配置与可塑性上限的**基因组**；品种提供模板，诞生时引入受控随机变异。
- **品种**：电子狗世界的谱系名（如「平原猎手」），**不是现实犬种**。

### 4.3 身份证（16 位）

```
[出生地 2 位][出生日期 8 位][品种码 2 位][个体序号 4 位]
```

示例：`0120260728010001` — 出生地 `01`，2026-07-28，品种 `01`，当日序号 `0001`。

## 五、机器语言与交流

### 5.1 母语

电子狗之间的交流**原生格式是机器语言**：

- 底层：位序列 / 十六进制指令流
- 结构：操作码 + 操作数 + 校验段（类比真实指令集）
- 语义：由它们世界的协议栈解析，**不是人类语言翻译版**

示例（概念展示，非最终实现）：

```
[TX] 0xA3 0x01 0x7F 0x2C   ; 向邻近个体发送采集请求
[RX] 0xB1 0x01 0x00 0x4E   ; 应答：接受
```

### 5.2 协议文明

在机器语言之上，电子狗文明发展出：

- **总线协议**——短距离通信规范
- **包格式**——结构化消息（狩猎协同、工具共享、科研数据）
- **存档格式**——知识传承的序列化标准

它们科学水平与现实人类同步，因此也有等价于「高级语言」「编译器」「网络协议」的文明成果——但**个体间即时交流仍回归机器语言**。

### 5.3 玩家如何「听懂」

玩家是外部观察者，界面提供两层：

| 层 | 内容 |
|----|------|
| **原文层** | 机器语言流（hex / 二进制 / 汇编风格） |
| **旁注层** | 开发者提供的译解（方便玩家理解，**不是世界内语言**） |

旁注类似纪录片字幕，**不属于电子狗世界**。
