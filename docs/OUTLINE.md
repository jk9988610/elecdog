# 电子狗（ElecDog）项目大纲

> 版本：v0.2 草案  
> 状态：架构设计阶段  
> 平台：GitHub Pages → 安卓 APK  
> 仓库：elecdog

---

## 一、项目愿景

打造**电子狗世界**——一个由电子狗自主运转的文明模拟。这里的「电子狗」不是现实犬类的仿制品，而是该世界中**自洽的智慧物种**：它们在本世界里被定义为**「人类」**——正如我们在现实世界里定义自己的同类。

核心原则：

- **世界自成一体**：电子狗不需要玩家也能狩猎、造工具、交流、发展科学；它们的世界中没有现实人类。
- **不追求全面模拟**：只在特定情景里做到足够细、足够像；条文过长则主动优化抽象层级。
- **基因决定个体**：每只电子狗由细胞与 DNA 决定初始状态，品种是**电子狗世界的谱系**，不是现实生物分类。
- **玩家是外来观察者**：目前电子狗**看不见玩家**；远期通过「电子人」实体让玩家进入它们可感知的层面——**当前阶段不做电子人**。
- **先 Web 后原生**：GitHub Pages 验证世界与 AI，再移植 APK。

## 二、世界观总览

### 2.1 两个世界的对应关系

| 现实世界 | 电子狗世界 |
|----------|------------|
| 人类 | 电子狗（世界内称「人类」） |
| 玩家（不可被感知） | 远期：电子人（可被感知，未实现） |
| 现实犬种 / 生物基因 | 电子狗品种 / 电子基因 |
| 生物死亡 | 电子死亡（机制见 §5，待确认） |

### 2.2 电子狗文明（当前设定）

电子狗已具备与现代人类**同步的科学技术水平**，并在此基础上发展出：

- **狩猎**——获取资源与能量
- **工具使用与创造**——从简易器具到复杂装置
- **沟通交流**——语言、协作、社会结构
- **科学发展**——研究、记录、传承知识

它们有社会、有个体身份、有生死与伤病——但一切规则遵循**电子世界的物理与逻辑**，而非现实生物学。

### 2.3 玩家的位置（Phase 0）

```
┌─────────────────────────────────────┐
│  玩家（现实世界）                    │
│  · 创建世界                          │
│  · 观察、干预（有限）                │
│  · 暂不可被电子狗感知                │
└──────────────┬──────────────────────┘
               │  （远期：电子人实体）
               ▼
┌─────────────────────────────────────┐
│  电子狗世界                          │
│  · 平地起步，纯文本呈现              │
│  · 电子狗自主运转                    │
│  · 无现实人类                        │
└─────────────────────────────────────┘
```

## 四、世界与呈现

### 4.1 世界创建

玩家创建一个**世界**。初始状态：

- 地形：**一块平地**（无图、无高度）
- 呈现：**纯文本**
- 默认出生地点编号：`01`
- 世界中已有（或即将诞生）自主运转的电子狗个体

### 4.2 个体文本表示

```
{名字}（{品种名}）
```

示例：

```
豆豆（平原猎手）
```

- 默认名字：`小狗`
- **品种**：电子狗世界的谱系名称，决定基因模板与社会角色倾向——**不是现实犬种**

### 4.3 电子狗身份证

纯数字串，建议 **16 位**：

```
[出生地 2 位][出生日期 8 位][品种码 2 位][个体序号 4 位]
```

示例：`0120260728010001`

| 字段 | 说明 |
|------|------|
| 出生地 | `01`–`99`，新世界默认 `01` |
| 出生日期 | `YYYYMMDD` |
| 品种码 | 电子狗世界品种注册表（非现实犬种编码） |
| 个体序号 | 同地、同日、同品种下的顺序号 `0001`–`9999` |

后期可增加校验位或基因指纹后缀——**待确认**。

## 五、生死、伤病与恢复（草案，待你确认）

> 电子狗会**死亡**，但这是**电子世界的死亡**，不是现实生物死亡。以下为三套可组合的机制草案，请你选择或修正。

### 5.1 电子死亡（建议语义）

死亡 = 个体**核心运行态不可自持**，意识流中断，身体（载体）进入「停机」状态。

可能触发原因（可多选，待确认）：

| 类型 | 描述 | 叙事色彩 |
|------|------|----------|
| **能量耗尽** | 长期未补给，核心电池归零 | 可预防 |
| **核心损毁** | 狩猎/事故/冲突导致核心模块损坏 | 突发 |
| **逻辑崩坏** | 病毒、极端环境、实验事故 | 罕见、戏剧性 |
| **寿命到期** | 设计寿命上限（若启用衰老） | 自然终结 |

### 5.2 受伤（建议语义）

受伤 ≠ 死亡。表现为**模块受损、功能降级**，例如：

- 运动模块效率下降
- 感知范围缩小
- 记忆缓存偶发丢失
- 工具操作失误率上升

受伤个体仍可行动、交流、求助；电子狗文明已有与之匹配的**维修/医疗体系**（具体名称与流程待确认）。

### 5.3 治疗（建议语义）

- **现场修复**：简易工具、同伴协助，恢复部分功能
- **维修站 / 医疗所**：世界内的固定设施，消耗资源与时间
- **完全修复**：功能恢复至伤前；**不完全修复**可能留下永久模块损耗（待确认是否允许）

### 5.4 复活 / 重启（建议语义，核心待确认）

| 方案 | 描述 | 代价 | 适用 |
|------|------|------|------|
| **A. 备份恢复** | 文明级意识备份存在时，载入最近快照 | 丢失备份后的记忆；消耗稀有资源 | 科技已同步的文明合理 |
| **B. 核心重载** | 同一载体重启，基因不变 | 记忆清空或严重残缺 | 偏硬核 |
| **C. 新载体转生** | 基因档案写入新个体，新身份证 | 社会身份延续规则待定 | 叙事空间大 |
| **D. 不可复活** | 死亡即永久，仅可纪念或继承遗产 | 无 | 偏残酷真实 |

**建议默认倾向**（可推翻）：采用 **A + 不完全备份**——复活可行，但记忆有缺口，且需消耗世界内资源；无备份则仅能通过 **C** 保留基因、失去连续意识。

## 六、生物学底层：电子细胞 → 电子 DNA → 表现

> 命名与结构借鉴生物学，语义属于**电子狗世界**，不映射现实物种。

### 6.1 层级结构

```
世界
 └── 电子狗个体
      └── 细胞群（逻辑模块：感知 / 运动 / 代谢 / 认知…）
           └── 电子 DNA
                └── 基因位点
                     └── 表现型（体质、认知倾向、社会角色、工具天赋…）
```

### 6.2 设计意图

- **细胞**：系统分区，非医学仿真
- **电子 DNA**：决定初始状态、可塑性上限、模块耦合方式
- **品种**：电子狗世界的谱系模板 + 随机变异 → 保证每只狗独一无二
- **与文明的关系**：基因影响个体擅长狩猎、研发、沟通等，但不锁死发展路径

### 6.3 与 AI 的关系

AI 读取基因派生参数 + 当前世界状态 + 社会上下文，在情景中决策。  
重点情景示例（待你选定首批 3 个）：

- 狩猎分工与收获分配
- 工具损坏后的协作修复
- 科学实验中的失败与记录
- 个体受伤后求援与维修
- 同伴电子死亡后的社会反应
