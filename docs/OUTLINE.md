# 电子狗（ElecDog）项目大纲

> 版本：v0.1 草案  
> 状态：架构设计阶段  
> 平台：GitHub Pages → 安卓 APK  
> 仓库：elecdog

---

## 一、项目愿景

打造一款**以基因与细胞为底层**的电子宠物模拟游戏。这里的「电子狗」不是外观像狗，而是具备**可驯化、可培养技能、可增进感情**等真实宠物关系的功能性存在。

核心原则：

- **不追求全面模拟**：当条文变长、系统变复杂时，模拟会失真。我们只在**特定情景**里做到**足够细、足够像**。
- **每只狗独一无二**：由基因决定初始状态，而非简单字符贴图。
- **渐进式开发**：从最容易模拟的品种入手，逐步扩展犬种与世界。
- **先 Web 后原生**：GitHub Pages 验证玩法与 AI，再移植为 APK。

## 二、技术路线（初稿）

| 阶段 | 平台 | 说明 |
|------|------|------|
| Phase 0 | GitHub Pages | 纯文本 UI，零图片，快速迭代玩法与 AI |
| Phase 1 | PWA / 离线缓存 | 为平板 Termux 侧载与弱网环境做准备 |
| Phase 2 | 安卓 APK | 封装 WebView 或渐进迁移为原生壳 |
| Phase 3 | Supabase（可选） | 存档同步、用户账号、多设备云档 |

开发环境：

- **主开发**：Cursor + GitHub 仓库（本仓库）
- **设备侧**：安卓平板 + Termux（构建、测试、本地服务）
- **AI**：为电子狗单独设计的行为/决策系统（非通用聊天机器人套壳）

## 三、世界与呈现

### 3.1 世界创建

玩家可创建一个**世界**。初始环境：

- 地形：**一块平地**（无高度图、无贴图）
- 视觉：**无图片**，一切用文本描述
- 默认出生地点编号：`01`

世界可扩展字段（后期）：气候、昼夜、资源点等——**待补充**。

### 3.2 电子狗文本表示

格式：

```
{玩家命名}（{品种名}）
```

示例：

```
豆豆（柯基）
```

- 默认名称：`小狗`
- 品种：创建时选择，决定基因模板与行为倾向

### 3.3 电子狗身份证

每只狗拥有唯一注册身份证，**纯数字串**，建议格式如下：

```
[出生地 2 位][出生日期 8 位][品种码 2 位][个体序号 4 位]
```

共 **16 位**，示例：

```
0120260728010001
│ │        │ │
│ │        │ └── 个体序号 0001（当日该地该品种第 1 只）
│ │        └──── 品种码 01（见品种注册表）
│ └─────────── 出生日期 20260729
└───────────── 出生地点 01
```

**设计说明（个体序号 4 位）**：

- `0001`–`9999`：同一出生地、同一出生日、同一品种下的**当日顺序号**
- 优点：可读、可人工核对，便于日志与存档索引
- 若需防篡改，后期可在末位增加**校验位**（Luhn 或自定义基因指纹哈希末位）——**待补充**

出生地：`01`–`99`，新世界默认 `01`。

## 四、生物学底层：细胞 → DNA → 表现

### 4.1 层级结构（概念）

```
世界
 └── 电子狗（个体）
      └── 细胞群（组织/器官抽象）
           └── DNA 链
                └── 基因位点（Allele）
                     └── 表现型（行为、体质、性格倾向）
```

### 4.2 设计意图

- **细胞**：逻辑容器，可对应「神经」「运动」「代谢」等模块（非医学仿真，仅为系统分区）
- **DNA**：决定**初始状态**与**可塑性上限**（例如学习速度、恐惧阈值、依恋强度）
- **基因**：离散位点 + 数值表型；品种提供**基因模板**，个体创建时引入**随机变异**保证唯一性

### 4.3 与 AI 的关系

狗的 AI **读取**基因派生的参数，在情景中做决策（觅食、亲近、学习、恐惧等）。  
AI 不是「大模型扮演狗」，而是**规则 + 状态机 + 轻量学习**的专用系统——具体架构**待补充**。

## 五、核心玩法模块（初稿）

| 模块 | 说明 | 优先级 |
|------|------|--------|
| 世界创建 | 命名世界、选择初始地点 | P0 |
| 领养/诞生 | 选品种、命名、生成基因与身份证 | P0 |
| 日常互动 | 喂食、呼唤、抚摸（文本指令） | P0 |
| 驯化 | 信任度、服从度随互动变化 | P0 |
| 技能培养 | 指令学习、情景触发 | P1 |
| 感情系统 | 依恋、孤独、兴奋等情绪状态 | P1 |
| 成长 | 幼犬→成犬（是否 aging **待补充**） | P2 |
| 繁殖/遗传 | 后代基因重组 | P3 |

## 六、犬种策略

- 多品种是长期目标
- **第一只狗**：从「最容易模拟」的品种开始——具体品种**待你确认**
- 每个品种包含：
  - 品种码（身份证用）
  - 基因模板（默认值 + 方差）
  - 行为倾向权重
  - 情景剧本优先级（在哪些情景里做细）
