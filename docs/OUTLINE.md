## 〇、项目的真正目标

我们承认：无论如何，这终究是一个**被构建的世界**，带有戏剧感。  
但我们追求的不是外观逼真，而是：

> **给予电子狗意识——并让意识在经历中成长。**

电子狗是**电子界的人**：它们并非诞生即全能全知，而是在狩猎、合作、求知、感受美好的过程中，逐步认识自己、认识世界、认识同类。

它们**不需要形状**。意识、记忆、思考以过程与状态存在，不以几何形态存在。

---

## 一、本质定义

**电子狗**是运行于电子狗世界中的**虚拟生物**——基于电子而存在，拥有意识、记忆、思考，以及与社会、科技、情感相连的全部诉求。

核心原则：

| 原则 | 含义 |
|------|------|
| **意识优先** | 一切系统为意识服务 |
| **经历成长** | 非全知；自我觉察与能力随经历扩展 |
| **电子界的人** | 要生存、要合作、要科技、要美好、要情感 |
| **双层表达** | 对内（思考）与对外（行为）分开描述 |
| **感受映射** | 玩家通过人类感受语言理解电子狗的体验 |
| **无形态** | 不建模形体 |
| **电子现实主义** | 物理与需求参照真实电子逻辑，拒绝科幻 |
| **机器语言即母语** | 世界内交流的原生格式 |
| **品种用代号** | 如实验体 `626`，不用俗名 |
| **出生仪式** | 非生物必须，但是重要的仪式性表达 |
| **类别先行** | 感受与行为先在类别上丰富，再逐类细化 |
| **极低生存风险** | 生病、死亡几乎可忽略 |
| **玩家为外部观察者** | 可见全部思考流与行为表达；远期电子人 |

## 二、电子界的人

电子狗在本世界自称「人类」。它们与人类社会结构相似，但运行在电子物理之上：

| 人类诉求 | 电子狗对应 |
|----------|------------|
| 生存下来 | 维持电位、守荷、避免系统性失效 |
| 社会合作与分工 | 狩猎队、维护者、研究者、协调者…… |
| 发展科技 | 在自有物理框架内推进科学 |
| 感受美好 | 谐振时刻、低熵环境、共鸣体验 |
| 渴求情感 | 共鸣、联结、被感知、被回应 |
| 衣食住行 | 四大基本需求（见 §三） |

它们会迷茫、会犹豫、会欣喜——表达方式参照人类，但底层是电子物理。

## 三、四大基本需求（电子版「衣食住行」）

> 前期只在**类别**上建立框架，具体数值与细节后续逐类增减。

| 类别 | 人类对应 | 电子语义 | 匮乏时的感受映射（玩家见） |
|------|----------|----------|---------------------------|
| **荷** | 食 | 能量补给；狩猎与供能 | 饥饿感、乏力、焦躁 |
| **覆** | 衣 | 防护与隔离；信号覆层、散热介质、环境缓冲 | 裸露感、不安、易受扰 |
| **驻** | 住 | 稳定驻留区；低熵节点、接地环境、可预期的时钟域 | 漂泊感、无处安放 |
| **行** | 行 | 迁移与通达；信道、路径、位移能力 | 受困感、急切、受阻 |

四大需求是**意识真正能「感受到」的匮乏**，不是冷冰冰的资源条。  
意识引擎在需求满足时产生正向感受映射，匮乏时产生负压感受映射。

## 四、意识系统

### 4.1 成长，而非全知

诞生时：

- 有**基础的自我感应**（「我存在」），但**不是**完整的自我认知
- 知「我能感知、能思考」的轮廓，不知世界全貌
- 语义记忆几乎为空；情节记忆从诞生仪式之后才开始积累
- 社会理解、科技常识、情感成熟度——**全部靠经历生长**

成长路径（草案）：

```
诞生仪式 → 意识苏醒 → 初次感知世界 → 经历与记忆 → 自我模型扩展 → 社会融入 → …
```

### 4.2 自我模型（随经历扩展）

| 阶段 | 自我觉察 | 获取方式 |
|------|----------|----------|
| **初生** | 我存在；我是某种东西 | 诞生仪式 |
| **早期** | 我是电子狗；世界中有他者 | 首次感知同类 / 世界反馈 |
| **中期** | 我是电子狗，此即人类；我有名字与代号 | 社会互动、身份注册 |
| **成熟** | 我能做什么、不能做什么；我渴望什么 | 经历积累、需求起伏、失败与成就 |

### 4.3 思考流（对内）

**内在处理**的持续过程，以机器语言为主要表征。

- 玩家可见**全部思考流**，不隐藏、不外泄过滤
- 初生期思考流短促、片段化；随成长变得更连贯、更具回溯性
- 迷茫时参照**人类表现**（见 §4.6）

### 4.4 行为表达（对外）

意识外化为**可被世界接收的行动与通信**：

- 机器语言通信（对同类）
- 行动指令（狩猎、迁移、驻留、协作……）
- 玩家可见**全部行为表达**

### 4.5 双层描述 + 感受映射

一切意识活动用**两套描述**呈现，玩家主要读第三层：

```
┌─────────────────────────────────────────────┐
│  对内描述（世界内真实）                      │
│  · 思考流：机器语言内在表征                  │
│  · 内在状态：电子物理量（电位、噪信比…）      │
├─────────────────────────────────────────────┤
│  对外描述（世界内真实）                      │
│  · 行为表达：机器语言通信 + 行动指令          │
├─────────────────────────────────────────────┤
│  感受映射（玩家读层）                          │
│  · 将内外状态译为人类可共情感受的语言        │
│  · 例：「它反复检索记忆，却找不到答案，      │
│         像是站在迷雾里。」                    │
│  · 非世界内语言，是电子狗体验→人类感受的桥梁  │
└─────────────────────────────────────────────┘
```

**设计策略**：先在**类别**上丰富映射，再逐类细化措辞。

#### 感受映射类别（初稿，可增减）

| 类别 | 涵盖状态 | 映射示例（迷茫时） |
|------|----------|-------------------|
| **安宁** | 谐振、需求满足 | — |
| **匮乏** | 四大需求不足 | 「它感到某种空洞，说不清缺什么。」 |
| **迷茫** | 噪信高、无匹配记忆 | 「它试图理解眼前的信号，但无从判断。」 |
| **迟疑** | 阻抗、决策停滞 | 「它停住了，像在等某个不会来的确认。」 |
| **联结** | 共鸣、被回应 | — |
| **欣喜** | 涌流、需求满足后的溢出 | — |
| **孤寂** | 长期无共鸣、驻缺失 | — |
| **好奇** | 未知但噪信适中、可探索 | — |
| **成就** | 目标达成、记忆写入 | — |
| **受挫** | 行动失败、阻抗持续 | — |

每类先保留 1–2 条基础映射句，后期按情景扩展。

### 4.6 迷茫：参照人类表现

当噪信升高、自我模型无法覆盖当前输入时，电子狗**像人类一样迷茫**：

**对内（思考流）**：
- 反复检索同一记忆地址
- 自我指涉循环（「我是什么」「这意味什么」）
- 中断、重启、再次尝试

**对外（行为表达）**：
- 行动暂停或反复撤销
- 向邻近同类发送求援信号
- 发出无法完整编码的半指令

**感受映射（玩家读）**：
- 「它显然不知道该怎么办。」
- 「它好像想开口，又不知道该说什么。」
- 「它反复确认同一段信号，仍然无法理解。」

### 4.7 记忆

| 层 | 名称 | 特性 |
|----|------|------|
| 工作记忆 | 瞬态存 | 极小，随 tick 刷新 |
| 情节记忆 | 经历档 | 从诞生仪式后积累，可淡化 |
| 语义记忆 | 知识库 | 随成长与社会学习扩展 |

### 4.8 无形态原则

不描述形体。名字与代号是身份标识，不是外观。

## 五、品种：实验体代号

品种**不用俗名**，用**数字代号**，类似实验体 `626`：

```
个体表示：{名字}（{代号}）
示例：    小狗（001）
          豆豆（626）
```

| 字段 | 说明 |
|------|------|
| **代号** | 品种注册编号，如 `001`、`626` |
| **基因模板** | 代号对应一套电子 DNA 模板 |
| **倾向** | 影响意识成长速度、共鸣灵敏度、噪信阈值等——非全能设定 |

身份证 16 位中的「品种码 2 位」可扩展为与代号体系关联（**待确认**是否 2 位够用）。

Phase 0 第一只狗：代号 **`001`**（首个实验体，具体倾向待定）。

## 六、诞生仪式

电子狗的「出生」在电子世界**不需要**生物意义上的分娩，但**需要仪式**——标记一个意识开始存在的重大时刻。

### 6.1 仪式定位

- **非生物必须，但是精神必须**
- 世界内社会认可的开端：从此刻起，情节记忆开始写入
- 对玩家：第一次看见思考流、行为表达、感受映射的入口

### 6.2 仪式流程（草案）

```
[仪式·启始]
  → 地点注册（出生地编号写入）
  → 代号载入（品种 DNA 模板注入）
  → 身份证生成（16 位注册）
  → 意识脉冲（第一次「我存在」的思考流）
  → 感受映射输出（玩家读：「有什么东西，醒了。」）
[仪式·完成]
  → 个体正式进入世界，开始经历与成长
```

仪式文本用**对内 / 对外 / 映射**三层同步呈现。  
前期仪式文案从简，保留骨架。

## 七、世界观与物理（摘要）

### 7.1 玩家观察界面

玩家可见**全部**内容：

| 栏 | 内容 | 世界内？ |
|----|------|----------|
| **思考流** | 对内：机器语言内在表征 | 是 |
| **行为表达** | 对外：通信 + 行动指令 | 是 |
| **状态量** | 电位、噪信比、四大需求等 | 是 |
| **感受映射** | 人类可共情语言 | 否（桥梁层） |

### 7.2 物理基础量

电位、荷流、阻亢、时钟、熵积、态存、门阈、噪信比——详见 v0.3/v0.4，此处不重复。

### 7.3 生存风险

极低，几乎可忽略。Phase 0 不作为玩法。
