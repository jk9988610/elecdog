| ID | 内容 | 可证伪 |

## 二、实现

| 组件 | 路径 |
|------|------|
| 完整智慧栈 | `W5_WISDOM_FULL` — W1–W4 全开 |
| 长时 tick | `FIELD_WISDOM_OPEN_TICKS = 8192` |
| 对照 | `w5_std_1920` vs `w5_open_8192` |
| 田野 | `npm run field:phase77` |

### 机制（最小）

- 1920 tick 基线 vs 8192 tick 开放尺度对照
- 检验 PRD / SOC-ENC / MEM-LIN 信号随时间尺度扩展
- 对外率长/短差异 + 层信号缩放（layerScale）
- **不预制**「智慧」「意识」等地球语义
