## 一、内核扩展

| 机制 | 作用 |
|------|------|
| `ehuCoherence` | 寄存器漂移稳定性（自我连续） |
| `ehuDistinction` | 自发行为 vs 社会接收区分度 |
| `electronicHumanArc` | 档案层 + RPR 跃迁累计叙事弧 |
| `resolveElectronicHumanStage` | H0→H3 阶段解析 |
| `electronicHumanActBias` | 阶段调制 ACT |
| `[EHU]` | 阶段跃迁记录 |

### 阶段（H0–H3）

| 阶段 | 含义 |
|------|------|
| H0 | 初态（幼体或弧不足） |
| H1 | 可追踪（连贯性低） |
| H2 | 整合（多层档案活跃） |
| H3 | 叙事（高弧 + 自我区分） |
