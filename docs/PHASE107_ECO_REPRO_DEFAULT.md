# Phase 107 · 默认生态有丝分裂（淘汰续行）

> **一条主因果**：`wisdom_evolution` 及之后默认环境 → **环境门控 FISS**（有丝分裂类比），**关闭 REN/PLG 续行**；减数（MEI/FUS）非默认，仅在显式处理组开启。

---

## 变更

| 项 | 之前 | 之后 |
|----|------|------|
| 默认繁殖 | FISS + MEI/FUS + REN 续行 | **FISS 生态分裂** |
| `rplRenewEnabled` | true（智慧演化场） | **false** |
| `meiEnabled` / `fusEnabled` | true | **false**（默认） |
| `ecoFissEnabled` | 仅 Phase 106 留置 | **全局默认** |

---

## 机制（`ECO_REPRO_BASE`）

- **有丝分裂类比**：`fissionGate` — 场富足、低胁迫、膜完整 → `[FISS]`，亲代不 END
- **无续行**：`tryRplRenew` 在 `ecoFissEnabled` 下对全体跳过
- **不扣 RPL**：生态分裂不消耗复制配额（环境即许可）
- **历史处理组**：显式 spread `REN_BASE` / `MEI_BASE` 的 Phase 仍可复现旧对照

- `wisdom_evolution`
- `observer_wl_stack` / `observer_w6_stack`
