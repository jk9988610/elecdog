## 一、内核扩展

| 机制 | 作用 |
|------|------|
| `meiRplDeduct: active` | 子域 RPL 模式下 MEI 仅扣**当前轮值子域**（非全体子域） |
| `hasMeiReplicationBudget` | 子域模式：任一子域有配额即可 MEI |
| `consumeReplicationForMei` | 统一 MEI 扣减逻辑；事件 meta 含 `organismType`/`rplScope` |
| FUS 子代 | 继承环境 `organismMode` → 多细胞重组体保留 `[ORG]` 形态 |

## 三、结论

| 假说 | 结果 |
|------|------|
| H1 多细胞可触发 MEI | **support**（48–60 次） |
| H2 子域 RPL 更易积压 packet | **support**（积压 36 vs 24） |
| H3 子域 FUS 仍可完成 | **support**（FUS 48，F/M≈0.8） |
| H4 修复包提升 F/M | **support**（共享：1.0→1.81） |
| H5 重组子代保留多细胞 | **support**（重组多细胞 24） |
| H6 子域+修复包仍高积压 | **weak**（积压 29 vs 36，未降至单细胞水平） |

**解读**：

- 多细胞 × 重组路径**成立**；重组子代全部为 `multicell`。
- 子域 RPL 产生更多 MEI（60）但也更多 packet 积压；Phase 44 修复包对**共享 RPL** 效果显著，对**子域 RPL** 积压缓解有限。
- 单细胞锚定 F/M≈1.92；多细胞共享+修复 F/M≈1.81 — 接近 parity。
