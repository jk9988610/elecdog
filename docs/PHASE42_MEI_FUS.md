# Phase 42 · 减数缩减 [MEI] / 双源汇合 [FUS]

> **决策**：在克隆分裂 `[FISS]` 与续行机制之后，引入 **双源 DNA 重组** 繁殖路径，  
> 不设「配子」「性别」「受精」等地球专有名词进 CODEX。

---

## 一、两步繁殖路径

| 标签 | 操作定义 | 地球类比（观察用，非 CODEX） |
|------|----------|------------------------------|
| **[MEI]** | 各位点从 DNA 原文随机解析 → `meiPacket`；消耗 1 RPL | 减数分裂 / 单倍体包形成 |
| **[FUS]** | 同 tick 双体 `meiPacket` 汇合 → 重组 DNA 新个体 | 双源遗传物质融合（非性别配对） |

与 `[FISS]` 区别：FISS 为 **单亲克隆**；FUS 为 **双源重组**。

## 三、结论

| 假说 | 结果 |
|------|------|
| H1 FUS 路径可观察 | **support**（14 次/跑） |
| H2 关闭 FISS 时无克隆分裂 | **support**（FISS=0） |
| H3 绝对 DNA 多样性高于克隆 | **unsupport**（11 vs 13，种群较小） |
| H4 重组路径可维持种群 | **support**（存活 11） |
| H5 双路径可并存 | **support**（FISS 8 + FUS 3.5） |

**解读**：

- **减数→汇合** 路径可独立维持种群（无 FISS 时 FUS 14 次），标志双源重组繁殖成立。
- 多样性 **比率** 在重组路径更高（11/11=1.0 vs 13/16=0.81），但绝对序列数受种群规模影响。
- 双路径并存时 FISS 仍主导（8.25 vs 3.5 FUS），重组为次要路径。
- 严格耗尽环境下 MEI 高频但 FUS 稀少（316 vs 4），提示 **减数包积压** 需配对才能释放。
