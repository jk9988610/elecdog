## 三、结论

| 假说 | 结果 |
|------|------|
| H1 `[REN]` 提升 FISS | **support**（12→32，恢复至无 RPL 上限水平） |
| H2 `[REN]` 事件可观察 | **support**（均值 56 次/跑） |
| H3 `[PLG]` 提供额外续行路径 | **support**（36.5 次/跑；与 REN 并存） |
| H4 种群规模回升 | **support**（16→36） |

**解读**：

- 富足场下 RPL 耗尽并非终局；`[REN]` 在配额见底后持续概率回补，使分裂与种群回到「开放场」水平。
- `[PLG]` 在同 tick 双体耗尽时触发，减少个体级 `[REN]` 依赖（REN 56→19.5），但总量仍维持顶格分裂。
- 二者均为 **可观察的续行通道**，不引入性别或减数分裂语义。
