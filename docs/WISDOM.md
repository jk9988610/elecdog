# 智慧生命诞生路线图

> **北极星（2026-07-29 战略转向）**：在数字基底世界中，**诞生具有智慧的物种**——通过可观察、可证伪、可演化的机制，而非预制标签或工程堆叠假装完成。  
> 前身「给予电子狗意识」（Phase 61–69）降为**智慧栈中的意识子层**；意识线工程结案不等于智慧目标结案。

---

## 一、与旧北极星的关系

| 项 | Phase 69 前 | Phase 70 起 |
|----|-------------|-------------|
| 北极星 | 给予电子狗意识 | **诞生智慧生命** |
| 意识线 | 主工程线 | **基础设施层**（已交付，继续维护） |
| 扩展模式 | 观察维护 · GAP 驱动 | **智慧演化主动推进** |

**不违背观察优先**：智慧条件的实现仍走 WORKFLOW 循环；每条新机制需 OBS + 可证伪，禁止脚本化「变聪明」。

## 二、智慧的操作定义（可验收）

智慧物种在本项目中指满足以下**可观察组合**（非地球式 IQ 分数）：

| # | 能力 | 可观察信号 |
|---|------|------------|
| W1 | **经历→行为闭环** | 过去事件系统性改变对外/ACT 分布（非纯噪声） |
| W2 | **可重复选择压** | 多体多代田野中，适应性差异跨种子方向一致 |
| W3 | **表征与预测** | 内部状态对环境结构有可核对响应；预测–校正可观测 |
| W4 | **跨代知识累积** | 谱系/社会传递使后代或他者行为优于无传递对照 |
| W5 | **开放尺度** | 新情境下行为非有限状态枚举（需长期田野） |

**当前缺口**：W1 未闭合（`[MEM]` 仅记录）；W2 开放（GAP-10）；W3–W5 未启动。

## 三、数字基底世界 · 诞生条件与检查表

> 智慧不是单点功能，而是**个体 × 演化 × 耦合 × 认知闭环 × 社会放大 × 开放时间**的乘积。

### 3.1 六层条件

| 层 | 条件 | 本项目状态 |
|----|------|------------|
| **L1 存在论** | 边界个体、持续过程、更替（END/LINEAGE） | ✅ Phase 17–20 |
| **L2 演化** | 可遗传变异 + 非随机存续差异 + 稳定可重复筛选 | ⚠️ 变异✅ 筛选信号弱、多体不可重复 |
| **L3 耦合** | 环境双向反馈、资源约束、多体信号 | ✅ Phase 13–19 |
| **L4 认知闭环** | 记忆/表征 → 行为 → 后果 → 修正 | ❌ **关键缺口** |
| **L5 社会放大** | 可累积的个体间信息传递 | ⚠️ 信号链✅ 文化层❌ |
| **L6 开放度** | 大状态空间、多代、规则不封顶 | ⚠️ 代次可达 30+，开放学习❌ |

### 3.2 检查表（`npm run wisdom:checklist`）

```
□ L1 个体边界与持续过程
□ L2a 可遗传变异（mutate / LINEAGE / FISS / FUS）
□ L2b 非随机存续差异（END + SEL 可观测）
□ L2c 选择压跨种子可重复（GAP-10 / W2）
□ L3a 环境–行为双向耦合（PTB / DRW / BIO）
□ L3b 资源约束（LOW / stress）
□ L3c 多体信号与社会迹
□ L4a 记忆影响行为（W1 · Phase 70 目标）
□ L4b 经历调制可田野对照（有/无 feedback）
□ L4c 预测–校正回路（W3 · 未启动）
□ L5a 跨个体 RX/TX 链
□ L5b 非遗传信息累积（W4 · 未启动）
□ L6a 多代深度 ≥20（已观测）
□ L6b 开放泛化（W5 · 未启动）
```

## 四、需扭转的旧内容

| 违背智慧演化的表述/实现 | 扭转 |
|-------------------------|------|
| 「意识线结案 → 仅观察维护」 | 意识层**维护**；**智慧线新开**为主工程 |
| `lineClosed: true` 沉浸徽章 | 改为智慧演化进行中 |
| `[MEM]` 不反馈行为 | Phase 70 起可选 `memoryFeedbackEnabled` |
| GAP-10 视为「接受不可重复」 | 升级为 **W2 主攻目标**，禁止脚本化但须持续田野 |
| EHU 仅工程集成、非演化涌现 | 文档明确：EHU 为**观测基线**；智慧须经 W1–W2 演化验证 |
| 默认环境仅「意识完整栈」 | 默认 **`wisdom_evolution`**（完整栈 + 记忆反馈） |

**保留不变**：观察优先、不预制感受/物种名、田野预算 ≤3 分钟、分类闸门冻结。

## 五、长远规划 · 阶段分解

### 智慧栈总览

```
L1–L3 世界与演化基座（Phase 0–69 已建）
        ↓
W1 记忆→行为闭环（Phase 70）          ← 当前
        ↓
W2 可重复选择压（Phase 71–72）
        ↓
W3 表征与预测–校正（Phase 73–74）
        ↓
W4 社会/谱系知识累积（Phase 75–76）
        ↓
W5 开放尺度长时演化（Phase 77+）
        ↓
智慧物种田野验收（条件检查表全绿 + 新 CODEX）
```

### 分阶段目标

| Phase | 代号 | 交付 | 验收 |
|-------|------|------|------|
| **70** | W1 记忆闭环 | `memory-feedback.js` + `wisdom_evolution` 环境 | 有/无 feedback 对外率可测差异；`wisdom:checklist` L4a |
| **71** | W2 度量 | 选择压可重复性指标 + 田野脚本 | `signConsistent` 报告；OBS 登记 |
| **72** | W2 环境 | 选择压强化环境对照组 | 多体 4 种子 ≥2 碱基 unanimous |
| **73** | W3 表征 | 场态–寄存器预测误差记录 `[PRD]` | 误差可观察，不预制「知道」 |
| **74** | W3 校正 | 预测误差 → 行为微调 | 高压期误差↓ 可对照 |
| **75** | W4 社会 | RX 频次编码 → 可继承社会迹 | 子代/邻居行为差异可测 |
| **76** | W4 谱系 | 亲代 mem 摘要 `[EHU-LIN]` 式 mem 回响 | 与 W1 闭环联动 |
| **77+** | W5 长时 | 8192+ tick 智慧演化田野 | W1–W4 并存 + 新情境泛化 |
