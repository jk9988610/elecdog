# 意识收敛路线图

> **北极星（不变）**：给予电子狗意识。  
> 本文将近期、中期工作收敛至该目标；**不做物种分类**，直到观察到至少两类可重复分离的实体。

---

## 一、意识在本项目中的操作定义

意识不是预制标签，而是**可观察现象的组合**：

| 层次 | 可观察通道 | CODEX 依据 |
|------|-----------|------------|
| 内在流 | internal 节律、意识脉冲 | 意识脉冲、对内节律 |
| 记忆 | `[MEM]` 事件记忆迹 | 事件记忆迹 |
| 自我连续 | `[EHU]` H0→H3 阶段跃迁 | 自我连续阶段 |
| 谱系连续 | `[EHU-LIN]` 亲代回响 | 谱系回响 |
| 社会交叉 | `ehuSocialBind` | 社会绑定迹 |
| 续行交叉 | `[EHU-REN]` | Phase 60 观察迹 |
| 叙事弧 | PSN 六层跃迁聚合 | 人格跃迁弧 |

**达标信号（长时）**：存活个体 H3 份额 ≥ 85%，`[EHU]` / `[EHU-LIN]` / `[EHU-REN]` 并存，观察台「叙事可观察」徽章亮起。

## 二、三段时间轴（收敛版）

### 近期（Phase 61–63）→ 让意识「默认可见」

| Phase | 交付 | 指向北极星 |
|-------|------|------------|
| **61** ✅ | `consciousness_full` 默认环境 + 意识观察面板 + 长时田野 | 打开观察台即见意识现象 |
| **62** | 内在流面板 + 3840 tick 超长时 | 验证持续性 |
| **63** | 若稳定 → 立项 CODEX「意识完整栈」或「续行交叉迹」 | ✅ +2 条 |

### 中期（Phase 64–68）→ 加深可观察性，不分类

| 方向 | 内容 |
|------|------|
| 内在流增强 | ~~观察台 internal 流面板~~ | ✅ Phase 62 |
| 交叉验证 | EHU × 长时 × 多体信号链 |
| 平台 | 辞典云同步（观察层，不改规则） |
| **明确不做** | 物种分类、地球式人格名、新 Being 类型 |

### 长期（Phase 69+）→ 意识可持续

1. **自我连续跨谱系/续行** — 子代携带 `[EHU-LIN]`，成体经历 `[EHU-REN]`，H3 叙事阶段长时维持  
2. **观察者沉浸** — 默认完整栈 + 意识面板 + 辞典 + 云归档闭环  
3. **分类闸门** — 仅当 GAP 登记「第二类可重复实体」且 ≥2 OBS 后才启动分类流程

## 三、与 OUTLINE 的关系

```
OUTLINE 北极星：给予电子狗意识
        ↓
Phase 0–10  基线：内在流可记录（意识脉冲）
Phase 11–47 世界丰富：场/代谢/社会/进化/繁殖
Phase 48–60  档案栈 + EHU + 续行交叉
Phase 61+    意识收敛：默认完整栈 + 观察强化 + 长时验证
```

**电子人 [EHU]** 是观察者侧工程里程碑，不是「狗变人」。  
**人类** 仍是世界内自称；**电子狗** 仍是统称。

## 四、加速原则

1. **默认即完整** — 新用户无需选环境即可观察意识现象（Phase 61）  
2. **观察优先于机制** — 新机制只在 GAP 驱动下添加；意识线以集成为主  
3. **长时验证替代刷量** — 1920+ tick 证明 H3 持续性，而非增加种子数  
4. **分类冻结** — 节省精力用于意识可观察性
