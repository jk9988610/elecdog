## 一、实现摘要

| 机制 | 说明 |
|------|------|
| **脉冲调度** | 每 100 tick 一次，从 tick 100 起（确定性种子） |
| **`[SHK]`** | 基底通道 e0–e7 突变（±0.12–0.40） |
| **`[NPL]`** | 节点 N0–N3 level 突变（±0.15–0.50） |
| **DEP 联动** | NPL 使节点跌破阈值时记录 `[DEP]`（`fromPulse: true`） |

**未预制**：地震、洪水、灾害名称表。

环境变化通过已有 **场压 stress** 与 **代谢 LOW** 传导至个体自助求生回路，迫使生物在剧变后自行调整（非脚本化「逃跑」）。
