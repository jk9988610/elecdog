## 二、工作流

```text
合并 main → CI build-ota → Pages 发布 updates/www.json + zip
                ↓
用户打开 APK → 拉清单 → 下载 zip → 自动刷新（无需重装）
```

仅当 `android/` 或 Capacitor 插件变更时：提高 `versionCode` + 更新 `apk.json` + 发新 APK。
