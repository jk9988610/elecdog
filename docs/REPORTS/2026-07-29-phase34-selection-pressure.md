## 三、解读（观察事实）

### 1. 基底耗竭 `sparse_substrate` — **强选择压 support**

- **幼体 END 率 → 100%**：谱系续行个体几乎**全部**在出生后 80 tick 内终止
- LOW 事件暴增（9254 vs 基线 2612）— 摄取失败链可观察
- LINEAGE 次数高：高死亡率 → 高周转，**不是**繁殖成功

**含义**：在「环境场持续贫瘠」下，**即时独立 + 单亲复制**对幼体**极不友好** — 若存在「延迟独立 / 成体通量喂养」，在统计上才有空间（尚未实现，仅为选择压推论）。

### 2. 组合高压 `harsh_combined` — **同上，support**

- 幼体 END 率 ≈ 100%，SHK 加倍，LOW 最高
- 最接近「逼出胎生+哺乳类比」的**环境配方候选**

### 3. 仅幼体摄取削弱 `juvenile_fragile` — **与预期相反（unsupport）**

- 幼体 END 率 **下降**（0.12 vs 0.50）
- LINEAGE 总数减半 — 种群周转变慢，**不是**幼体更易死
- 可能原因：整体 END 减少 → 谱系个体更少进入统计分母；**单一旋钮不足以模拟哺乳依赖**

### 4. 仅高频 SHK — **弱/混杂**

- 幼体 END 率与基线接近；SHK 翻倍但筛选信号弱
- 剧变 alone **不足以**推翻 LINEAGE 模式

### 5. 净谱系与终局存活

- 四环境下 **终局存活谱系个体仍 ≈4**（四体槽位填满）
- **选择压体现在幼体期死亡率**，而非种群灭绝 — 与 Phase 17「END 必 LINEAGE」闭环一致

## 四、对「性别/交配/哺乳」路线的含义

| 结论 | 说明 |
|------|------|
| **环境选择压存在** | `sparse_substrate` / `harsh_combined` 下幼体独立生存统计上失败 |
| **未证明需要两性** | 本批未实现双亲/哺乳，只证「即时独立吃亏」 |
| **下一田野** | 在 harsh 环境下对照：**单亲 LINEAGE** vs **延迟独立 + 成体通量转移**（引擎最小扩展） |
| **仍禁止** | 预制性别名、写进 CODEX |
