## 交付物

| 文件 | 作用 |
|------|------|
| `manifest.webmanifest` | 应用清单（由 `sync-version` 生成） |
| `sw.js` | Service Worker 离线缓存（版本化 CACHE） |
| `src/pwa.js` | 注册 SW + 离线徽章 |
| `icons/icon.svg` | 应用图标 |

## 行为

- 首次在线访问后，静态资源写入 Cache Storage
- 断网时可加载观察台壳层并继续运行已缓存模块
- 标题栏显示 **离线** 徽章（`navigator.onLine === false`）
- 版本发版：`package.json` → `npm run sync-version` → 自动刷新 SW 缓存名

## 验证

1. 打开 https://jk9988610.github.io/elecdog/（标题栏 **v0.25.0**）
2. DevTools → Application → Service Workers：已注册
3. DevTools → Network → Offline → 刷新：页面仍可加载
