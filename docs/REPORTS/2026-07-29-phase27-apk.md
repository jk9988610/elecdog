---

## 二、本地构建 APK

前置：安装 [Android Studio](https://developer.android.com/studio) 与 Android SDK。

```bash
npm install
npm run cap:sync          # 同步 Web 资源到 android/
npm run cap:open          # 用 Android Studio 打开工程
# 或在 SDK 就绪后：
npm run apk:debug         # 产出 android/app/build/outputs/apk/debug/app-debug.apk
```

云环境无 SDK 时，`cap add android` 与 `prepare:www` 已验证；Gradle 构建需本机 SDK。
