# 田野观察报告 · Phase 19 · 2026-07-29

> **生物圈反馈 + 种群结构观察** · 环境为主导，不预制地球生物类比

---

## 一、设计原则（回应用户）

| 原则 | 实现 |
|------|------|
| 环境与生物**共同塑造** | 种群活动累积 → `[BIO]` 改变基底场（类似地球生物改大气，但不叫「氧气」） |
| 种群组成**可观察** | `[CMP]` 记录 structIdx 等数值，**不贴**人类/蘑菇标签 |
| **环境为主导** | 只加最小耦合（residue 累积）；结构指数从田野数据生长，非需求表驱动 |

---

## 二、机制

### `[BIO]` 生物圈反馈
- 每 tick 个体活动向 `residue` 累积（寄存器−场态差 × 活动量）
- 每 50 tick 或超阈值施加到基底 e0–e7
- 记录：`[BIO] pop {n} e{i} ±δ after {值}`

### `[CMP]` 种群结构迹
- 每 100 tick 快照：pop、codes、lineageRoots、codeHom、lineageHom、spread、**structIdx**
- **structIdx 高** → 谱系/代号趋同（簇状倾向）
- **structIdx 低** → 谱系分散 + 社会位覆盖广（网状倾向）
- **仅为可观测指数**，待更多田野决定是否命名

### 初步观察（假说，非定论）

- **低密度**：单谱系续行 → structIdx 稳定偏高（簇状）
- **高密度多代号**：谱系分散、社会位全覆盖 → structIdx 偏低（网状）
- 与地球「分化多细胞体 vs 菌丝网状体」**仅作对照思考**；本世界尚未证实任何组成机制定律
