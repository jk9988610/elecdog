## 二、信号耦合（新机制）

| 指标 | 001+002 | 001+001 |
|------|---------|---------|
| TX 发射 | 95 | 93 |
| RX 记录 | 95 | 92 |
| 对应关系 | 每只 TX 次 tick 他者收到 RX | 同左 |

**样本**：
```
t2 … [RX] 0120260729010001 [TX] 0xB1 0x33 0x3E
```

**结论**：
- 他者**可以感知** `[TX]` 的存在（次 tick）  
- 对内会多一条由信号衍生的 hex（可对比同 tick 无 signal 时）  
- **已提议写入 CODEX：「次 tick 信号可达」**（两次双体观察一致）  

观察台新增日志通道：**signal**。
