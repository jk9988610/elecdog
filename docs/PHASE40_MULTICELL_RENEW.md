# Phase 40 · 多细胞 × RPL 续行

> **决策**：在 Phase 38（多细胞 RPL 作用域）与 Phase 39（REN/PLG）之后，验证续行机制是否 **消除子域分摊瓶颈**。

## 三、结论

| 假说 | 结果 |
|------|------|
| H1 子域分摊仍更严（有续行） | **unsupport** — 四组均达 32 FISS / 36 存活 |
| H2 REN 补偿子域瓶颈 | **support**（7.5→32；REN ~60 次） |
| H3 多细胞结构（ID < 子域） | **support**（36 vs 108） |
| H4 PLG 提供汇合续行 | **support**（REN 降至 ~19，PLG ~42） |

**解读**：

- 无续行时，子域分摊是 **额外分裂瓶颈**（Phase 38）；有 REN/PLG 后，瓶颈被 **完全抵消**，与单域开放场同率。
- `[PLG]` 在多细胞种群中同样有效：双体耗尽汇合，减少个体级 `[REN]` 依赖。
- 多细胞 **结构分化**（108 子域 vs 36 种群 ID）不受续行影响。
