# Phase 114 · 观察台混编批次导入

> 从田野报告按 **run（处理组 × 种子）** 一次载入 ≤2 carry + naive，对齐田野混编队列。

---

## 使用

1. 观察台 → **导入留置**
2. 选择报告 JSON
3. **混编 run** 下拉选处理组 × 种子
4. 设置 naive 数量（默认 4）
5. **载入混编批次**

单条载入仍用「载入单条」。

```bash
npm run observer:carry-batch
```

---

## 队列结构

```
naive × N（0 代） + carry × ≤2（留置快照）
```

与田野 `buildMixedCohort` 同构，观察台默认 naive=4（田野为 10）。
