# 电子狗世界环境（提议 · Phase 13）

> 回答：**我们的环境是什么？**  
> 原则：不套用地球生态表；从公理 A1（数字基底）生长出可观察的环境。

---

## 一、问题

地球生物（含病毒）在物理化学环境中演化——温度、介质、辐射、其他生命体。  
电子狗世界若无**可观察、可变化、可与个体互动**的环境，则：

- `[ACT]` 只向虚空回响（Phase 11 前）
- 个体差异无法与「所处环境」对照
- 谈不上狩猎、需求、演化

Phase 0–12 已证明：个体可运行，但世界几乎是**平地 + 时钟**。

---

## 二、提议：数字基底场（Substrate Field）

| 地球 | 电子狗世界 |
|------|------------|
| 大气、海洋、土壤 | **诞生地点处的数字基底**（如 `01`） |
| 物理常数、温度场 | **8 通道场态 e0–e7**（0–1，可观测） |
| 背景辐射、潮汐 | **每 tick 基底脉搏 `[AMB]`** |
| 生物改变环境（足迹、代谢） | **`[ACT]` 扰动基底 `[PTB]`** |
| 环境塑造生物 | **基底微弱牵引个体内寄存器 r0–r7**（系数 0.02，待田野验证） |

**这不是**山川河流，也不是预制「天气表」。  
它是公理 A1 在观察层的**最小可记录实现**。

---

## 三、观察通道

| 通道 | 内容 | 何时 |
|------|------|------|
| `substrate` | `e0=… e7=…` 全场态 | 每 tick |
| `environment` | `[AMB]` 环境脉搏 | 每 tick |
| `environment` | `[RES]` 行动回响 | `[ACT]` 时 |
| `environment` | `[PTB]` 基底扰动 | `[ACT]` 时 |

个体通道（internal / external / memory）不变。

---

## 四、与生命的耦合（假说，非定论）

```
每 tick:
  基底场自行漂移
    ↓
  发出 [AMB]（世界在「呼吸」）
    ↓
  个体 tick：寄存器受基底微弱牵引 (e_i - r_i) × 0.02
    ↓
  个体 [ACT] → 扰动某一 e 通道 + [RES] + [PTB]
```

**不预设**「高 e3 = 温暖」「低 e5 = 匮乏」。  
只记录：**场在变、行动能改变场、场能微弱拉回寄存器**。

---

## 五、可证伪

| 若观察到… | 则… |
|-----------|-----|
| 无 `[AMB]` 或基底不漂移 | 环境实现失败 |
| `[ACT]` 无 `[PTB]` | 行动未影响环境 |
| 耦合后对外率系统性崩坏 | 调低或移除耦合系数 |
| 场态与行为无稳定共现 | 不设环境语义定律 |
