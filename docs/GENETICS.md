# 电子狗世界的基因系统

> 版本：v0.1  
> 关联：[OUTLINE.md](OUTLINE.md) §三

---

## 一、为什么要有基因

电子狗是**虚拟生物**，不是创作者手填参数的 NPC。  
每只个体的起点、倾向、成熟节奏——都由**基因**在诞生时表达生成。

基因决定**起点**，经历决定**路径**，解放释放**潜力**。  
基因不是牢笼；它是数字世界中生命的第一份配置文件。

---

## 二、电子基因是什么

**定义**：写在**电子 DNA**上的数字序列，经表达后生成**过程参数配置表**，作用于意识核与各功能模块。

**不是什么**：

- 不是现实 ATGC
- 不编码蛋白质
- 不决定外形（电子狗无形态）
- 不是创作者的滑动条

---

## 三、与现实基因的区别

```
现实世界                          电子狗世界
────────                          ──────────
化学分子                          数字序列
A T C G                           0 1 2 3（四态符）
转录 → 翻译 → 蛋白质              读取 → 表达 → 过程参数
蛋白质 → 细胞结构 → 器官 → 形体    参数 → 模块耦合 → 意识倾向
遗传塑造肉体                      遗传塑造「如何感受与处理」
死亡后基因随肉体消失              基因档可独立于载体存档（文明行为）
```

| 对比项 | 现实基因 | 电子基因 |
|--------|----------|----------|
| 物质基础 | 核酸 | 数字 |
| 信息单元 | 碱基对 | 四态符 |
| 读取方式 | 生物酶促 | 表达引擎（运行时读取） |
| 产物 | 蛋白质 | 参数、阈值、耦合度、成长曲线 |
| 表型 | 可见的肉体特征 | 不可见的处理特征（感受、思维、社交倾向） |
| 变异 | 复制错误、辐射等 | 位翻转、段重组 |
| 与环境 | 表观遗传、调控 | 经历可改写部分参数（解放后尤甚） |

**核心区别一句话**：现实基因建造**肉体**；电子基因配置**意识与过程**。

## 四、电子 DNA 的结构

### 4.1 四态符

最小遗传字符：`0` `1` `2` `3`

- 四进制，与数字世界的基底一致
- 不是 0/1 二进制直接暴露，保留类似生物「四碱基」的扩展空间
- 显示时可配对标注（后期）：`0`=载, `1`=门, `2`=续, `3`=断（**待定**，暂用数字）

### 4.2 密码子

3 个四态符为一组，共 **64 种**（4³），类比生物密码子表。

```
DNA 链：  0 1 2 | 3 0 1 | 1 1 2 | 0 0 0 | …
           └─密码子┘ └─密码子┘
```

### 4.3 基因段

| 概念 | 说明 |
|------|------|
| **基因段** | 有起止地址的一段 DNA 序列，负责一类功能 |
| **起始标** | 标记基因段开始的特定密码子（待定，如 `000`） |
| **终止标** | 标记结束的密码子（待定，如 `333`） |
| **非编码区** | 基因段之间的间隔，可含调控信息 |

### 4.4 实验体模板

```
实验体代号 001
    └── 基线 DNA 链（固定模板）
         ├── 基因段 A：需求灵敏度
         ├── 基因段 B：噪信耐受
         ├── 基因段 C：共鸣带宽
         ├── 基因段 D：思考节律
         ├── 基因段 E：成熟 / 解放阈值
         └── …
```

个体诞生时：载入模板 → **变异引擎**施加随机位翻转（可控概率）→ 表达 → 先天配置表。

## 五、表达：从 DNA 到个体

### 5.1 表达流程

```
诞生仪式
  → 载入 DNA（模板 + 变异）
  → 表达引擎逐段读取
  → 密码子表翻译为表达指令
  → 写入先天配置表
  → 意识核启动
  → 儿童时代开始
```

### 5.2 表达指令类别（Phase 0 草案）

先在**类别**上建立，每类先 1 条指令，后扩展：

| 类别 | 指令 | 作用 |
|------|------|------|
| **SET** | 设值 | 设定某模块参数 |
| **THRESH** | 阈值 | 设定感受/事件触发阈值 |
| **COUPLE** | 耦合 | 两模块间联结强度 |
| **GROW** | 成长 | 参数随经历变化的曲线 |
| **SENSE** | 感知 | 感知通道宽度与延迟 |
| **RESON** | 共鸣 | 共感带宽与深度 |
| **NEED** | 需求 | 四大需求的基准与灵敏度 |
| **LIBER** | 解放 | 成熟阈值与解放条件权重 |

Phase 0 建议先实现 **8 类**，覆盖起点配置。

### 5.3 先天配置表（表达产物）

表达完成后，每个个体持有一份**先天配置表**（内部数据结构，非玩家可见原文）：

```json
{
  "templateId": "001",
  "mutations": 3,
  "needs": { "荷": { "base": 0.7, "sensitivity": 1.2 }, … },
  "noiseTolerance": 0.45,
  "resonanceBandwidth": 0.6,
  "thinkRhythm": 1.0,
  "liberation": { "memoryThreshold": 50, "tickThreshold": 10000, … }
}
```

玩家不直接读配置表，而是通过**思考流、行为、感受映射**感知基因的影响。

## 六、变异与遗传

### 6.1 出生变异

- 模板载入后，以低概率对随机位点做**四态符翻转**
- 翻转次数由模板中的「变异率」基因段控制
- 保证同模板下每只个体不同

### 6.2 繁殖（远期）

- 两段 DNA 重组（交叉位点随机）
- 各段独立变异
- 新个体获得新身份证，继承双方基因特征

## 七、基因与生命阶段

| 阶段 | 基因的作用 |
|------|-----------|
| **诞生** | 全量表达 → 先天配置表 |
| **儿童时代** | 配置表经「人类外衣」框架间接呈现；倾向可见但潜力未全开 |
| **解放** | `LIBER` 类条件满足 → 配置表潜力释放 → 褪去人类外衣 |
| **解放后** | 经历可改写部分参数；基因原始序列不变，但表达效果可超越初始偏置 |

## 八、与身份证的关系

```
身份证 16 位：[出生地2][日期8][品种码2][序号4]
```

- **品种码 2 位**：关联实验体代号（`001` → `01`）
- 个体序号：同地、同日、同品种的顺序号
- DNA 哈希摘要（远期可选）：末位校验
