# 进化与生命层级（路线 · Phase 17）

> 回答：自然界如何进化？电子狗世界里「生命」到哪一步？下一步是什么？  
> **本文是路线与假说，不是已证实定律。**

---

## 一、自然界中的进化（对照）

进化 ≈ **可遗传差异** + **变化的环境** + **非随机的存续差异** + **时间上的谱系改变**。

不是「变强」，是**在环境里被留下或被淘汰**。

---

## 二、本世界的生命层级（提议）

| 层级 | 状态 | 说明 |
|------|------|------|
| **L0 DNA 原文** | 已有 | 遗传信息，**单独不是生命** |
| **L1 个体（当前）** | Phase 17 起 | ID + DNA + 寄存器 + 内在/对外 + **场压反馈** |
| **L2 独立细胞** | Phase 20 起 | 代谢域边界 + 膜完整性可观察 |
| **L3 种群** | Phase 23 起 | 资源枯竭 DEP 与 END 共现；种群可维持；structIdx 稳定在网状区间 |
| **L4 进化** | Phase 26 起 | `[SEL]` 记录 END 时平均场压；筛选信号可观察、定律未立 |
| **L5 智慧** | Phase 70 起 | W1–W5 认知闭环与开放演化；见 [WISDOM.md](WISDOM.md) |

**「电子狗」** 是世界内对这类存在的**统称**（类似它们自称「人类」）。  
**每个个体不是「一只电子狗」这种物种实例**，而是带 DNA 的独立质点。

## 三、Phase 17：自助求生（已实现）

### 场压反馈
- `stress` 由 \|r−e\| 与基底匮乏合成
- 高压时：更易对外、偏向 `[ACT]`、ACT 偏向高 level 节点

### 存续终止 `[END]`
- 连续 `[LOW]` 或持续高压 → 个体停转（可观察）

### 谱系续行 `[LINEAGE]`
- `[END]` 后以亲代 DNA **变异** 诞生子代（`mutate` 3%）
- **防止种群只减不增**；为将来淘汰/适应提供原材料

**仍不预制**：饥饿、本能、猎物、角色名。

## 四、Phase 18：环境剧变（已实现）

### 脉冲调度
- 每 **100 tick** 一次可观测脉冲（从 tick 100 起，确定性种子）
- 不设灾害名称表

### 观察通道
| 标记 | 含义 |
|------|------|
| `[SHK]` | 基底通道 e{n} 突变 |
| `[NPL]` | 节点 N{n} level 突变 |
| `[DEP]` | NPL 致节点枯竭（`fromPulse`） |

### 与自助求生的耦合
- 剧变改变场态/节点 → 场压 stress 上升 → 已有 Phase 17 反馈（对外、ACT、END、LINEAGE）
- **不脚本化**个体对灾害的「正确反应」

## 五、Phase 19：生物圈与种群结构（已实现）

### 生物圈反馈 `[BIO]`
- 种群活动累积改变基底场（世界↔生物双向）
- 不设代谢物/氧气名称表

### 种群结构迹 `[CMP]`
- 每 100 tick 记录 structIdx 等可观测指数
- **簇状 vs 网状倾向**从田野生长，不预制地球生物组成标签

### 田野初现
- solo：structIdx ≈ **0.63**（簇状）
- 四体：structIdx ≈ **0.29**（网状）
- 密度与谱系分散度可能是结构分化的环境因子（待重复验证）

## 七、Phase 20：细胞边界（已实现）

### 代谢域
- DNA+ID 哈希分配 **4/8** 基底通道为膜内代谢域
- 摄取优先膜内；膜内匮乏时跨域 `[MBR]`
- 膜完整性 integrity + 低完整性 `[CEL]`

### L1→L2 路线
- 完整个体 = ID + 过程 + 自助 + **边界代谢域**（观察中，非定论）

## 八、可证伪

| 若… | 则… |
|-----|-----|
| 高压下 ACT 与随机期无差异 | 自助反馈失败 |
| END 后无 LINEAGE | 谱系续行失败 |
| 子代 DNA 与亲代完全相同 | 变异机制失败 |
| 无 SHK/NPL 或脉冲 tick 不规律 | 剧变实现失败 |
| 剧变后 SVV/END 与无剧变基线无差异 | 环境—个体耦合失败 |
| 无 BIO 或 pop=0 时仍有 BIO | 生物圈反馈失败 |
| solo 与多体 structIdx 无差异 | 结构指数无区分力 |
| 无 cellBoundary 或 CEL 不可核对 | 细胞边界失败 |
