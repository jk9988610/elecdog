# Phase 41 · 续行代价 [RCO]

> **决策**：Phase 39 续行可无限顶格分裂（32 FISS）；本阶段为 REN/PLG 引入 **可观察代价**，  
> 模拟「端粒酶式延寿」的代谢/寿命成本，而非继续放开分裂。

---

## 一、[RCO] 操作定义

每次 `[REN]` 或 `[PLG]` 成功后附加（`rplRenewCostEnabled`）：

| 代价类型 | 效果 |
|----------|------|
| 胁迫累积 | `stressStreak` +3（PLG ×1.2） |
| 寄存器消耗 | 全寄存器 −0.05 |
| tick 债务 | `renewTickDebt` +28；`rplTickCap` 缩短 |
| 概率衰减 | 每次 REN 后续概率 −0.035 |
| 次数上限 | 单个体 REN+PLG ≤14 次 |
| 债务终止 | `tickCount + renewTickDebt ≥ 260` → `[END] renew_tick_debt` |

## 三、结论

| 假说 | 结果 |
|------|------|
| H1 代价降低分裂率 | **unsupport** — 稳态仍 32 FISS |
| H2 RCO 可观察 | **support**（56 次/跑） |
| H3 债务致 END | **support**（~35 债务终止/跑） |
| H4 种群低于免费续行 | **unsupport** — 稳态仍 36（LINEAGE 回补） |
| H5 PLG 在代价下仍有效 | **support**（PLG 38.5，REN 降至 17.5） |

**解读**：

- 代价**不压缩稳态种群顶**，而是将系统推入 **高周转态**：END 从 0 暴增至 ~288，谱系续行 `[LINEAGE]` 持续补缺。
- 这与「代价性延寿」的生物学观察一致：复制能力可维持，但 **个体寿命缩短、更替加速**。
- `[PLG]` 在代价下仍分担续行（REN↓、PLG↑），RCO 总量不变。
