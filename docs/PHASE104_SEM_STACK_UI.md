## 类比映射（不进 CODEX）

| 原版 | 类比 |
|------|------|
| `[SEM] pair` | 反复出现的发–收型 |
| `semCount` | 约定迹条数 |
| `[SEM-LIN]` | 谱系残留迹 |
| `[TX]` / `[RX]` | 发信 / 收信 |
