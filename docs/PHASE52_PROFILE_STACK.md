# Phase 52 · 四层档案整合

> **统计田野**：12 体 × **960 tick** × 4 种子；  
> EXP + REG + MTB + COOP 四层同时启用，检验并存与繁殖兼容性。

---

## 一、整合设计

| 层 | 通道 | Phase |
|----|------|-------|
| 阅历 | `[EXP]` | 48 |
| 寄存器 | `[REG]` | 49 |
| 代谢 | `[MTB]` | 50 |
| 合作 | `[COOP]` | 51 |

**观测组**：四层积累，无反馈  
**反馈组**：四层全部 `*Feedback: true`  
**双路径组**：反馈 + 多细胞 `[FISS]`/`[MEI]`/`[FUS]` 竞争

---

## 二、田野（960 tick × 4 种子 × 12 体）

| 处理组 | 说明 |
|--------|------|
| `fertile_no_stack` | 对照（无档案层） |
| `fertile_stack_observe` | 四层观测 |
| `fertile_stack_feedback` | 四层反馈 |
| `fertile_stack_dual` | 四层 + 双路径 |

运行：`npm run field:phase52`
