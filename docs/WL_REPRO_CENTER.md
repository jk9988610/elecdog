# 智慧语言 · 繁殖核心收敛（WL-R）

> **2026-07-30 战略收敛**：智慧语言不再与繁殖平行两条轨，而以**繁殖为核**，「衣食住行」为**服务繁殖的智慧交流四域**——在电子狗世界中用可观察机制消化含义，不用地球生殖/生活词典。

---

## 一、收敛后的北极星

在数字原生世界中，形成**以繁殖信息交换为核、可观察、可证伪、可演化**的智慧语言：

1. **繁殖核（CORE-R）**：半态、许可、合胞、通量、外排、依赖期、谱系变异——PAIR / FISS / MEI 等已建机制上的 `[TX]`/`[RX]` 载荷共现与跨代 `[SEM-LIN]`
2. **四域交流（Y/S/Z/X）**：个体为完成繁殖生命周期所需的**边界·通量·依附·位移**信息，以 SEM 约定迹统计呈现，服务 CORE-R 而非独立「生活模拟」
3. **环境塑形 + 留置混编**：六环境链塑造躯体与载荷迹后，与 0 代在繁殖场混跑（Phase 129–130 已贯通）

**不是**：地球式语言、衣食住行名词表、恋爱/家庭/性别叙事。

## 二、CORE-R · 繁殖核（已建机制）

```
信息线：DNA（跨代） + meiPacket/dockedHalf（瞬时半态）
        ↓
PAIR 链：MEI → PRQ → PGR → FLD-CH → FLD-CH-IN → FUS-IN → EMB → EXP → NUR
生态链：FISS / LINEAGE / FUS（对照与默认繁殖）
留置链：harsh 塑形 → … → 混合繁殖场（129/130）
```

| 标签 | 繁殖核含义 | 田野状态 |
|------|------------|----------|
| `[MEI]`/`[DCK]` | 半态形成 | ✅ PAIR |
| `[PRQ]`/`[PGR]` | 许可交换 | ✅ PAIR-2 |
| `[FLD-CH]`/`[FLD-CH-IN]` | 半态场交换 | ✅ PAIR-3 |
| `[HRM]` | 多维门控向量 | ✅ PAIR-4 |
| `[FUS-IN]`/`[EMB]`/`[EXP]`/`[NUR]` | 合胞–通量–外排–依赖 | ✅ PAIR-0→4 |

**智慧语言在核上的任务**：高共现载荷对出现在繁殖事件邻域（±N tick）的可重复统计，并经 `[SEM-LIN]` 跨代残留。

```

        ↓
```

### WL-R1 操作定义（Phase 131）

| 项 | 内容 |
|----|------|
| 机制 | `[SEM]` 记录增加 `domain: YI|SHI|ZHU|XING|CORE-R`（由邻域事件推断，非词典） |
| 邻域 | 繁殖标签 ±`semReproWindow`（默认 24）tick 内的 RX→TX 对标记域 |
| 田野 | `ev131_wlr_chain_full` vs `pair0` vs `sem_plain`；检验 CORE-R 对密度 |
| 禁止 | 预制「衣食住行之词」、地球生活 CODEX 名 |

实现：`src/world/sem-lineage.js` · `npm run field:phase132:verify`

### WL-R2 操作定义（Phase 132）

| 项 | 内容 |
|----|------|
| 机制 | `semReproLineage` — PAIR-EXP 时 CORE-R 域迹优先写入 `[SEM-LIN]` |
