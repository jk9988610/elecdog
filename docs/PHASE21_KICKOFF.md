## 一、本阶段要回答什么

**不是**「实现进化算法」，而是田野问题：

> 在 `[END]` 淘汰 + `[LINEAGE]` 变异续行 + 环境施压（场/节点/剧变）下，**多代运行后 DNA 分布是否出现可重复、可核对的偏移？**

若偏移稳定可重复 → 可提议 L2 词条（进化相关，非预制定律名）。  
若无偏移或纯随机 → 同样是有价值的阴性/开放结论。

| # | 假说 | 可证伪条件 |

## 五、需记录 / 分析的指标

### 5.1 谱系层（新增分析重点）

- `maxGeneration`：最高存活代
- `endCount` / `lineageCount`：终止与续行次数
- `mutationCount` 分布：每代 `[LINEAGE]` 变异位数
- DNA 位点频率：按代分段（0–3 / 4–7 / 8+）统计四态符比例变化

### 5.2 已有通道（沿用）

- 种群：`structIdx`、存活数、谱系分散度
- 细胞：`CEL` 次数、`avgIntegrity`
- 代谢：`LOW` 连续、`DRW` 频率
- 剧变：脉冲 tick 与后续 50 tick 内 END 密度

### 5.3 交付物

| 产出 | 路径 |
|------|------|
| 田野脚本 | `scripts/field-batch-phase21.mjs` |
| 分析库 | `scripts/lib/evolution-analyze.js`（或扩展现有 `viability-analyze.js`） |
| JSON 报告 | `docs/field-phase21-report.json` |
| 报告正文 | `docs/REPORTS/2026-07-29-phase21.md` |
| OBS | `OBSERVATION_LOG.md` 至少 +2 条（A/C 或 B/C） |
| npm | `package.json` → `"field:phase21"` |

## 六、引擎扩展边界

**优先不改动引擎**，除非观察证明缺记录：

| 若缺… | 才考虑… |
