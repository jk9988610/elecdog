## 本地运行

用任意静态服务器打开根目录 `index.html`，或直接：

```bash
npx --yes serve .
```

## 田野批次

```bash
npm run field:phase26   # 最新：L4 环境筛选
npm run field:phase24   # 示例：GAP-02 寄存器
```

完整列表见 `package.json` 的 `field:phase*` 脚本。
